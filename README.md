Applicazione desktop per il tracciamento oculare tramite webcam con interfaccia grafica integrata.

---

## 📌 Cos'è
Papi Tracker Control è un programma che consente di attivare e gestire il tracciamento oculare in tempo reale tramite la propria webcam, grazie a un'interfaccia semplice e immediata con pulsanti di avvio/arresto e indicatore di stato.

---

1. Vai nella sezione **Releases** sulla destra di questa pagina (oppure clicca sulla versione pubblicata).
2. Scarica il file ZIP dell'applicazione allegato.
3. Estrai il contenuto del file ZIP sul tuo computer.
4. Apri la cartella ed esegui l'applicazione "EnricoTracker" per iniziare!
